MeshFit v0.2.0 is the first packaged release of the MeshFit add-in for SOLIDWORKS. It reverse
engineers scan meshes into native SOLIDWORKS surfaces, sketches and features.

**Pre-release:** several features have not been run inside SOLIDWORKS yet; see *What to test
first* below. Save your work before trying them.

## Download and install

1. Download `MeshFit-SolidWorks-addin-v0.2.0.zip` below and unzip it to a permanent folder, for
   example `C:\Tools\MeshFit\`.
2. Close SOLIDWORKS.
3. Right-click `register.bat` and choose **Run as administrator**.
4. Start SOLIDWORKS and open or create a part. The **MeshFit** tab is on the CommandManager ribbon.
   - If it shows old buttons from an earlier test build, right-click the CommandManager tabs and
     hide and show the MeshFit tab, or reset the CommandManager layout from *Tools > Customize*.
   - The first line of `%LOCALAPPDATA%\MeshFit\MeshFit.log` after start-up should read
     `MeshFit 0.2.0.0 connecting to SOLIDWORKS …`.

Requirements: 64-bit SOLIDWORKS 2018 or newer (built against the 2024 API; used on SOLIDWORKS 2026
SP3.2) and .NET Framework 4.8. To uninstall, run `unregister.bat` as administrator.

## What's in it

- **A ribbon in workflow order:** Scan → Align → Regions → Sketch → Model → Analyze → Output,
  with the names Geomagic Design X users know.
- **Region Groups mode:**
  - Auto Segment splits the scan into regions at creases and at fillets, then classifies each one
    (plane, cylinder, cone, sphere, torus, freeform);
  - fix regions with Paint Brush, Flood Fill, Rectangle, Freehand, Fillet Band, merge, enlarge,
    shrink;
  - ✔ keeps the regions; ✖ undoes the changes made in the mode (Redo brings them back).
- **Modeling wizards:** Surface Primitives, Extrusion Wizard, Revolution Wizard and Mesh Fit.
  - Click regions on the scan to add or remove them.
  - **Preview** shows the deviation map or the profile.
  - **✔** creates the SOLIDWORKS feature.
  - The pushpin keeps the wizard open for the next feature.
- **Mesh Sketch:**
  - pick a plane or planar face and an offset;
  - MeshFit sections the scan and fits lines and arcs;
  - **✔** writes an ordinary SOLIDWORKS sketch with relations, ready for Extrude, Revolve or Cut.
- **Clean geometry:** directions snapped to X/Y/Z and to other features, coaxial and tangent
  fillets, and round dimensions, all only where the scan agrees within tolerance.
- **Align Scan** (numeric, mates, automatic), **Accuracy Analyzer** (CAD vs scan), **fillet
  measurement**, **boundary curves**, **IGES export**, **project files**.
- **Right-click menu while painting:** brush size, edge angle, regions, wizards. **Delete** clears
  the active selection.

## Fixes since the last test build

- **SOLIDWORKS closing during region creation** (Region Groups and painting on large scans). The
  likely cause was a storm of screen refreshes and a Windows handle leak while hundreds or thousands
  of regions were created. Also in this release:
  - heavy work moved off SOLIDWORKS's main thread;
  - background suggestions limited on big scans;
  - overlay drawing made safer.
- **Align Scan / Position Mesh** failed to open on a scan without fitted regions.
- MeshFit now writes step-by-step breadcrumbs with memory and handle counts to
  `%LOCALAPPDATA%\MeshFit\MeshFit.log`.

## What to test first

1. Load `Microsoft Sculpt Keyboard.ply`, open **Region Groups**, and run **Auto Segment**.
   Classification runs in the background; Esc stops it.
2. Repeat with the large `fuse_mesh.ply`. On very large scans you can untick **Classify**
   before Auto Segment.
3. Open **Align Scan**.
4. Try **Surface Primitives** on a plane or cylinder region: click the region, Preview, then ✔.
5. Try **Mesh Sketch** on the Front or Top plane.

If anything fails or SOLIDWORKS closes, send:
- the end of `%LOCALAPPDATA%\MeshFit\MeshFit.log`;
- the SOLIDWORKS crash report if there is one.

## Known limitations

- Not yet run inside SOLIDWORKS: the wizards, Mesh Sketch, Rectangle/Freehand selection, and the
  pushpin "Lock" behaviour.
- On scans with millions of triangles, Auto Segment can create thousands of regions. Classifying
  them can take a long time in the background (Esc cancels; finished regions keep their type).
- Mesh Sketch supports planar sections only. There is no rotational method or draft compensation
  yet.
