Summary

What the established tools have in common

One linear workflow

The toolbar reads left to right in the order you work: scan, mesh clean-up, align, regions, sketch, model, compare. Geomagic for SOLIDWORKS is described as a linear left-to-right ribbon; Design X's Insert menu and toolbars follow the same order.

Regions come first

Design X's Region Group mode runs Auto Segment as soon as you enter it, colouring the whole scan by surface type. You then pick regions for features. Painting is for fixing regions, not the main way to select.

One wizard per feature

Surface Primitives, Extrusion Wizard, Revolution Wizard, Mesh Fit: each is its own command with a dialog. Each has a yellow region selection box, options, Preview, OK, and a Lock button that keeps it open for the next one.

Sketch from sections

Mesh Sketch cuts the scan with a base plane. Auto Sketch fits lines and arcs to the section with constraints. You then build the part with normal Extrude and Revolve. Mesh2Surface and QUICKSURFACE work the same way inside SOLIDWORKS.

Deviation always visible

Design X's Accuracy Analyzer pane works in every mode and while previewing primitives. Geomagic for SOLIDWORKS puts deviation analysis in every wizard.

MeshFit grew the other way: paint a feature, then Fit + Grow, then Create, all in one PropertyManager. That is why its tools and their positions don't match what users of these products expect.

Gaps, most important first

Where MeshFit differed, and the fix

  1. Paint-first instead of region-first

    Fix: the Region Groups mode runs Auto Segment on entry. It splits at sharp edges and at fillet bands from the curvature analysis, then classifies every region by fitting it. You edit regions instead of painting each feature from scratch.

  2. One PropertyManager did everything

    Fix: four separate wizards with their names from Design X: Surface Primitives, Extrusion Wizard, Revolution Wizard, Mesh Fit. Each takes regions as input and has Preview, OK, and the pushpin as Lock.

  3. No Mesh Sketch

    Fix: Mesh Sketch takes a base plane (a SOLIDWORKS plane, a planar face or a planar region) and an offset. It sections the scan, fits lines and arcs, and writes a normal SOLIDWORKS sketch with coincident, tangent, horizontal and vertical relations. Then you extrude or revolve with SOLIDWORKS's own commands.

  4. Ribbon not in workflow order

    Fix: Scan → Align → Regions → Sketch → Model → Analyze → Output, left to right, as in Geomagic for SOLIDWORKS.

  5. Missing standard selection shapes

    Fix: Rectangle and Freehand (lasso) modes that select front-facing visible triangles only. Paint Brush and Flood Fill keep their behaviour under the familiar names.

  6. Deviation only on demand

    Fix: every wizard's Preview turns on the deviation map for its regions. The Accuracy Analyzer keeps its own command for CAD-vs-scan checks.

A wizard PropertyManager

  • Regions: the regions this feature uses. Click regions on the scan to add or remove them.
  • Shape / options: shape (Surface Primitives), tolerance, Clean geometry, extension, control points.
  • Result: type, size and deviation per region after Preview.
  • ✔ creates the features; the pushpin (Lock) keeps the wizard open for the next ones.

The typical part, step by step

  • Import Mesh → Align Scan.
  • Region Groups: check the automatic regions, merge or repaint where needed, ✔.
  • Surface Primitives: pick the plane and cylinder regions, Preview, ✔.
  • Mesh Sketch on a plane through a flange → Extrude or Revolve in SOLIDWORKS.
  • Mesh Fit for the doubly curved skin.
  • Accuracy Analyzer to confirm the result.
